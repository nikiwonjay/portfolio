JobPilot

点击一个字段，找到对应的资料。
v1.0.19 · 可下载 / Edge 商店审核中

面向 Chrome 与 Edge 的网申填写辅助插件。把中英文求职资料整理在侧边栏，点击网页输入框后推荐候选资料，再由用户选择逐项填入。

React 19TypeScriptManifest V3PDF.js / MammothZodVitest
下载与安装 ↗技术说明 ↗
查看功能与实现思路
本地解析 TXT、DOCX 和文本型 PDF，管理教育、实习、项目与自定义记录。通过内容脚本识别当前字段及部分动态下拉、日期控件，侧边栏提供搜索、复制和单项填写。资料默认存储在浏览器本地；翻译与云端 AI 为可选功能。不会自动提交申请。仓库目前提供构建包和说明，尚未公开完整源码。
