JOBPILOT / PRODUCT WALKTHROUGH

界面、流程与实现。

将反复查找和复制简历信息的过程，收进浏览器侧边栏。保留用户选择，让每一次填写都有明确的资料来源。

01 / IMPORT

简历导入

支持 TXT、DOCX 与文本型 PDF。手动选择中文或英文，解析后导入资料库，减少逐条录入。

02 / ORGANIZE

中英文资料库

按教育、实习、项目等经历管理记录。支持搜索、复制、编辑和删除，方便找到要用的内容。

03 / EXTEND

自定义分组

新增证书、培训等 section，在分组中添加多条记录和字段，按自己的简历结构组织资料。

04 / MATCH

点击字段匹配

点击网页输入框后，根据字段关键词与上下文推荐资料。多段经历可指定来源记录，再选择填写。

05 / INTERACT

控件辅助选择

对可可靠识别的日期与下拉控件辅助选择。包含 Phoenix 日历适配，未适配的控件使用复制或手动填写。

06 / TRANSLATE

按需翻译

通过按钮触发翻译。浏览器支持时可使用本地翻译，也可配置自己的云端 AI 服务。

FOUR STEPS / 使用流程
01

导入并整理

选择语言，解析简历，将资料导入本地资料库。

02

连接当前网站

在招聘页面主动授权，启用点击匹配。

03

点击并选择

点击目标字段，选择候选资料或指定经历记录。

04

填写并检查

逐项填入，检查网页显示结果，再由用户完成申请。

实现重点：动态网页交互

基于 Manifest V3，将侧边栏、后台通信和内容脚本分开。通过 DOM 与 MutationObserver 识别字段和动态控件，再将用户选定的资料写入当前目标。

设计取舍：用户控制与本地优先

采用逐项填写流程，不自动提交申请或批量新增经历。资料保存在 chrome.storage.local；本地解析无需 API Key，云端 AI 仅使用用户配置的服务。
